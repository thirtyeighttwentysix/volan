# Volan 0.1.0-alpha.1

First Maven Central alpha of Volan, a schema-first ORM for Kotlin and Java on Java 17+.

This release includes schema parsing and validation, Kotlin client generation with a Java-friendly
API, PostgreSQL CRUD, relations, projections, aggregates, transactions, asynchronous operations,
introspection and migration tooling. APIs and generated source may change during the alpha series.

```kotlin
repositories { mavenCentral() }

dependencies {
    implementation(platform("io.github.thirtyeighttwentysix:volan-bom:0.1.0-alpha.1"))
    implementation("io.github.thirtyeighttwentysix:volan-runtime")
    implementation("io.github.thirtyeighttwentysix:volan-dialect-postgres")
    runtimeOnly("org.postgresql:postgresql:42.7.13")
}
```

Use `volan-codegen:0.1.0-alpha.1` for build-time client generation and `volan-migrate` for database
synchronization and migrations. The independent [release smoke project](https://github.com/thirtyeighttwentysix/volan/tree/v0.1.0-alpha.1/release-smoke)
demonstrates generating, compiling and running a client using only Maven artifacts.

Published modules: `volan-core`, `volan-schema`, `volan-ir`, `volan-codegen`, `volan-dialect-api`,
`volan-dialect-postgres`, `volan-runtime`, `volan-migrate`, and `volan-bom`.

MySQL, SQLite, H2, the coroutine adapter and a Gradle plugin are not included in this alpha.
The CLI can be built from this tag with `./gradlew :volan-cli:installDist`.

Release verification checks artifact metadata, checksums, signatures and Java 17 bytecode, then
generates and runs a Java client against PostgreSQL from an independent Gradle build. The release
workflow repeats artifact download verification and the consumer test after Central publication.
