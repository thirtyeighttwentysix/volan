# Volan CLI preview

Portable CLI archives for Windows, Linux and macOS, with SHA-256 checksums and user-level installers.
Requires Java 17 or newer. No administrator privileges are required.

The CLI includes `init`, `generate`, `format`, `validate` and `db` commands and supports PostgreSQL,
SQLite, H2, MySQL and MariaDB. `init` creates a schema; application project configuration is described
in `docs/build-plugins.md`.

This is a separate preview of the CLI from main. Maven Central libraries remain at alpha.2;
the alpha.3 library release is still in development.

Installation and upgrade instructions: https://github.com/thirtyeighttwentysix/volan/blob/main/docs/cli-installation.md
